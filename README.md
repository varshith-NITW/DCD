# Digital Circuit Design (DCD) Showcase Hub

A collaborative web application designed for ECE (Electrical and Computer Engineering) students and faculty to share, review, and collaborate on Verilog design modules.

## Features
* **ECE/Verilog Themed**: Sleek, glassmorphic dark-mode interface with hardware schematic placeholders for modules.
* **Pure Single Page Application (SPA)**: Open, review, edit, and delete Verilog design modules directly inside rich modal overlays without page redirection.
* **Multi-User Sync**: Integrates with Firebase Firestore for real-time data persistence across devices.
* **Access Control**: Distinct login portals for teacher administration and students, complete with uniqueness checks for usernames and display names.
